# About The App
Its a Discord inspired forum for research club. It has various pages which include:
- feed: for announcements
- General Chat: for community engagement
- Threads: To start a reddit style discussion thread on any topic
- Assignment: For easy submission of entries during competitions and medical events
- Blogs: To feature informative articles and tutorials
- Calendar: to keep track of events happening in the club
- Link: To external sites like socials.
Apart from these, for the core team to manage tasks and execute events:
- Tasks: to assign and keep track of events
To handle everything else:
- Admin: To whitelist emails of members so that only authorised members can login. Keep track of roles and calendars.
